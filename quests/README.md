# Пакеты приключений

`catalog.json` содержит относительные пути к `quest.json`. Загрузчик использует обычные статические файлы, поддерживает размещение в подпапке и GitHub Pages. Загрузка данных не исполняет JavaScript из пакета. При сборке содержимое пакетов включается в общий хеш версии.

У каждого пакета есть:

- `id`, целочисленный `version`, `title`, `subtitle`, `mode`;
- `trigger`: посещение `place` или пересечение северной границы `z`;
- `requires`: массивы `completed`, `items`, `flags`;
- `media`: относительные `scene`, `music` и текстовое описание `alt`;
- `rules`: номера связанных правил;
- `outcomes`: выдаваемые предметы `addItems`, изымаемые `removeItems`, изменения `flags`, деньги `credits`, доверие `trust`, затраты `minutes`, итоговый текст `text`, при необходимости маршрут `travel`.

Для `mode: "text"` задаются `entry` и словарь `nodes`. Узел содержит `title`, `speaker`, `text` (массив абзацев) и `choices`. Выбор: `id`, `text`, `next`, необязательные `set` (локальные переменные), `minutes`. Учебный выбор дополнительно имеет `correct`, `rule`, `feedback`; перед переходом игрок читает разбор. Порядок таких выборов меняется воспроизводимо по seed рейса.

Завершающий узел содержит `ending`: `outcome`, `summary`, `label`. В `ending.cases` можно задать альтернативы с условием `when` по локальным переменным. Изменения передаются общему миру только при подтверждении завершения. Сами локальные переменные сохраняются в записи законченного эпизода.

Текстовый пакет можно добавить в каталог без редактирования карты. Новая механика требует отдельного исполнителя в приложении; импортируемые данные не получают доступа к произвольному коду или браузерному хранилищу.

Три SVG и три короткие WAV-темы созданы для проекта. Темы — синтезированные оригинальные последовательности звуков. Нормативные тексты берутся из общего местного справочника; источники и редакционные изменения описаны в `docs/SOURCES.md`.
