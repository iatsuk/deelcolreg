# Quest Lab

Инструмент для квестов в духе «Космических рейнджеров 2». Модель не видит структуру написанного ею квеста, поэтому решатель показывает её числами: можно ли выиграть, выигрывает ли игра наугад, меняет ли исход знание правила, какие выборы ни на что не влияют.

Формат повторяет идеи QM: параметры с диапазонами и критическими значениями, локации, переходы с условиями и лимитами. Всё случайное проходит через взвешенные переходы, поэтому решатель считает вероятности точно, а не сэмплирует.

```bash
tools/questlab/ql check quests/freight/plombir.quest
```

Скрипт `ql` сам находит Node 24, даже если его нет в PATH. Команды:

| Команда | Что делает |
| --- | --- |
| `ql check <файл>… [--world radar=1,zaz=-1]` | Полный отчёт и пороги из `gates.json`, при необходимости в заданном состоянии мира. Код выхода 1, если порог не пройден |
| `ql compare <файл>…` | Таблица по нескольким квестам, `.quest` или собранным `.json` |
| `ql play <файл> [--new] [--move 2] [--seed 1]` | Слепой плейтест: один ход за вызов, без доступа к исходнику |
| `ql facts <файл>` | Всё, что помечено правилами, рядом с нормативным текстом, для сверки |
| `ql graph <файл>` | Граф в формате DOT |
| `ql build <файл>…` | Собрать `.quest` в `.json`, который читает игра |
| `ql bundle` | Собрать колоду, шаблон и поручения в `errands.json` |
| `ql deck` | Точно решить все поручения на всех маршрутах со всеми раскладами и в пяти состояниях мира |
| `ql gates` | Все контракты из каталога, имена из квестов и все расклады. Около минуты. Известные долги берёт из `waivers` в `gates.json`, закрытый долг требует убрать запись |
| `ql test` | Все тесты проекта |
| `ql site` | Собрать сайт в `dist/`, как это делает публикация |
| `ql coverage` | Матрица: какие правила проверяются, где и есть ли ловушки |
| `ql roll 12 20` | Жребий автора по таблицам из `quests/freight/STORY.md`. Все кости берутся из одного seed: секунды Unix-времени и наносекунды монотонных часов, так что два запуска seed не делят. `--seed N` повторяет бросок |

Исходник `.quest` — истина, `.json` рядом с ним собирается. Тест проверяет, что они совпадают.

## Как читать отчёт

- **Победа при лучшей игре** низкая: квест невыигрываем или слишком случаен.
- **Победа наугад** высокая: решения ничего не значат. У диалога с тестовым вопросом здесь 100%.
- **«Всегда самый длинный ответ»** высокая: верный вариант выдаёт себя длиной.
- **Решений, меняющих шанс на 5+ п.п.**: доля настоящих развилок. **Ложных выборов**: варианты с одинаковым исходом.
- **Знание правила**: сколько в среднем теряет тот, кто в этой точке гадает. «Партия» показывает шанс на всю игру: он может остаться высоким, если правило можно обойти другим маршрутом, и это само по себе полезное знание.
- **Ловушки**: цена конкретного заблуждения в момент выбора.

Пороги в `gates.json` — ориентиры для полноразмерного квеста, а не законы. Числа говорят о структуре и ничего не говорят о том, смешно ли это и хочется ли играть. Для этого нужен живой человек.

## Формат `.quest`

```
quest plombir                     идентификатор
title Три тонны пломбира
brief Одна строка для доски заказов
legal Необязательная оговорка на экране финала
rules 13 24 26                    покрытые правила
start intro                       стартовая локация

param t "Время" 1200..1900 =1260 fmt=clock     видимый параметр
param pl "Пломбир" 0..100 =100 kind=cargo      kind: cargo | threat | count
| 85..100 Звенит, если постучать               текст для диапазона значений
param spd "ход" 1..3 =2 hidden                 скрытый параметр
param zaz "память" -1..1 =0 hidden world       живёт дольше рейса

def fish = m1==2 and m2==1                     именованное выражение
fx leg = t+=60, pl-=5                          именованный эффект
crit sus>=100 -> caught                        проверяется после каждого перехода
news confess Текст                            строка в порту прибытия после этого финала
doc table "Таблица Кузьмича" when=table        предмет, который можно открыть
+ Красный над белым — рыбак за делом.

mast lights slots=m1,m2,m3 top=top nav=nav stock=lw,lr,lg values=3   мачта как игрушка

== cross                          локация; win | soft | fail | death делает её финалом
@roll side 1..2                   случайное значение при входе
@scene sea                        port | cape | sea | strait | dawn | court
@see patrol brg=22 dist=.42 aspect=-52 when=side==1    что видно из рубки
@mast lights                      на этой локации мачту можно менять
@title Заголовок
@speaker Кто говорит
@tags r15 r17                     правила, которые решаются здесь
! sus-=15                         эффект при входе
note 15 Текст для разбора         попадёт в разбор инспектора
?note fishy :: 26 Текст           то же при условии
Абзац текста, {t|clock}, {pl|text}, {money}.
? side==1 :: Абзац при условии.
> pl>=60 -> end-solid             автопереход, первое совпадение сверху
> -> a 60 | b 40                  взвешенный случайный переход

* Текст выбора
  if pos==1                       иначе выбор скрыт
  lock money>=30 | Не хватает     иначе виден, но заблокирован
  once                            исчезает после использования (или limit 3)
  ~ money-=30, lg+=1              эффекты
  : Реакция на следующем экране
  note 24 Текст для разбора
  #r24 #trap:tow-gap              правило и заблуждение; #good для верного варианта
  -> shop                         цель, можно несколько с весами
```

Выражения: числа, параметры, `def`, `+ - * / %`, сравнения, `and or not`, `a?b:c`, `min max abs floor round clamp`. Кода в квесте нет, `eval` не используется.

`aspect` у `@see` — пеленг на нас от носа чужого судна, плюс по правому борту. Огни рисуются по этому углу и секторам правила 21, поэтому красный и зелёный нельзя перепутать случайно.

## Части квеста

```
include ship                      подставить общий заголовок из deck/ship.quest
use tow exit=advance              вклеить встречу из deck/, выход ведёт в advance
param pl "Пломбир" 0..100 =100    параметр с тем же id заменяет общий
```

Встреча начинается с `encounter имя`, строкой `radar …` описывает себя для радара и выходит через зарезервированную цель `-> exit`. Её локации получают префикс: `cross.cross-held`. Начальная локация получает имя встречи, поэтому хост ссылается на неё просто: `> -> tow`.

Поручение начинается с `errand имя` и задаёт:

```
pay 160                           оплата, половина при частичном успехе
perleg 115                        минут на участок, отсюда срок
routes old-fish fish-light        откуда и куда, только по существующим переходам
set rate1=5 rate2=15 rate3=35     потери груза за участок и стартовые значения
cargo "Рояль"                     подпись груза, дальше диапазоны | от..до текст
```

Обязательные локации: `hook` (завязка, выход `-> go`), `event` (выход `-> on`), `win`, `soft`, `fail`, `late`. Для каждого финала нужна строка `news win …`. В тексте `{{to}}` заменяется на «в Рыбачью слободу». Порог оплаты 60 и 30, поэтому верхний диапазон груза должен начинаться с 60.

## Пределы

Решатель перебирает состояния с учётом живых переменных и останавливается на 2,5 млн. Если упёрлись, сообщение покажет, какие параметры размножают состояния. Обычно помогает огрубить числа до кратных пяти или обнулять ненужное значение.

Линтер ищет частые приёмы модели в русской прозе. Срабатывание повод перечитать, а не приговор.
