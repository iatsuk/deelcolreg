# Встраивание в deelstuff

Игра — автономная статика с относительными путями. Можно разместить всё содержимое проекта (или `dist/` после сборки) в `/colreg/` на домене блога. Для публичного каталога предпочтительна сборка, чтобы не отдавать документы и тесты.

```sh
npm run build
# разместить содержимое dist/ на https://<домен-блога>/colreg/
```

Вариант с iframe:

```html
<iframe
  src="/colreg/?embed=1"
  title="Дельный МППСС — тренажёр правил расхождения"
  style="width:100%;height:1350px;border:0;border-radius:14px"
  loading="lazy"
></iframe>
```

`embed=1` скрывает внешнюю шапку, вводный блок и подвал. Тренажёр, выбор темы и справка остаются. Высоту iframe следует настроить под макет блога; у него собственная прокрутка при необходимости. Для блога с жёсткой CSP нужны `script-src 'self'`, `style-src 'self' 'unsafe-inline' https://fonts.googleapis.com` (интерфейс использует inline style для индикаторов), `font-src https://fonts.gstatic.com`, а также разрешённый `frame-src 'self'`. При запрете внешних шрифтов можно убрать `@import` из `src/style.css`.

При размещении на том же домене прогресс доступен и на самостоятельной странице, и во встраивании. В стороннем iframe браузер может ограничить localStorage; игра покажет уведомление и продолжит работу в памяти. Для встраивания используйте доверенный собственный источник; с `sandbox` требуются как минимум `allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox`.

Ключ хранилища: `deelstuff.colreg.v1`. Данных аккаунта нет. Исходники ведутся в `iatsuk/deelcolreg`; веб-версия автоматически не развёртывается при push.
