# Встраивание в deelstuff

Игра — автономная статика с относительными путями. Можно разместить всё содержимое проекта (или `dist/` после сборки) в `/colreg/` на домене блога. Для публичного каталога предпочтительна сборка, чтобы не отдавать документы и тесты.

```sh
npm run build
# разместить содержимое dist/ на https://<домен-блога>/colreg/
```

Вариант с iframe:

```html
<iframe
  src="/colreg/"
  title="Ночной фрахт · Дельный МППСС"
  style="width:100%;height:1350px;border:0;border-radius:14px"
  loading="lazy"
></iframe>
```

Главная страница — игра «Ночной фрахт». Параметр `embed=1` прежнего учебника она не читает: внешней шапки и подвала у игры нет, а Impressum и Datenschutz открываются кнопкой «О проекте». Высоту iframe следует настроить под макет блога; у него собственная прокрутка при необходимости. Для блога с жёсткой CSP нужны `script-src 'self'`, `style-src 'self' 'unsafe-inline' ` (интерфейс использует inline style для индикаторов), `font-src 'self'`, `connect-src 'self'` (квесты загружаются как JSON), а также разрешённый `frame-src 'self'`. Шрифты уже хранятся локально; Google Fonts не используется.

При размещении на том же домене прогресс доступен и на самостоятельной странице, и во встраивании. В стороннем iframe браузер может ограничить localStorage; игра без уведомления продолжит работу в памяти текущей вкладки. Для встраивания используйте доверенный собственный источник; с `sandbox` требуются как минимум `allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox`.

Игра хранит прогресс под ключом `deelstuff.colreg.freight.v2`. Данных аккаунта нет. Исходники ведутся в `iatsuk/deelcolreg`; push в main запускает тесты и публикацию на GitHub Pages.
