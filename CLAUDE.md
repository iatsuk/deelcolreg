# Дельный МППСС

Здесь только то, чего не видно из кода. Обзор устройства лежит в `docs/FREIGHT.md`, отвечайте пользователю по-русски.

## Команды
`node` и `npm` на машине автора вне PATH, поэтому используйте обёртку:
- `tools/questlab/ql test`: все тесты, около секунды.
- `tools/questlab/ql gates`: контракты, имена и расклады, около минуты. Обязательно после правок в `quests/`.

## Границы
- Активный код: `src/freight*`, `src/quest-*`, `tools/questlab/`, `quests/freight/`. Живой учебник: `index.html` и `src/app.js`. Остальные страницы и модули это ранние прототипы: их не расширяем.
- Разрешённые импорты и лимиты заданы в `tests/structure.test.js`. Если тест мешает, меняйте код. Поднять лимит можно только с согласия пользователя.
- Долги в `waivers` файла `tools/questlab/gates.json` только сокращаются. Снизить порог или добавить долг можно только с согласия пользователя.

## Квесты
- Правьте только `.quest`, затем `ql build <файл>` для контрактов и `ql bundle` для колоды и поручений. JSON руками не трогаем.
- Новый квест пишем через навык `quest-forge`.
- Случайность идёт только через взвешенные переходы, иначе решатель не посчитает точные вероятности.
- Формулировки правил сверяем через `ql facts`, а не по памяти.
- Жребий для творческих решений бросаем командой `tools/questlab/ql roll 12 20` (seed — секунды и наносекунды), а не в уме. Таблицы — в `quests/freight/STORY.md`.

## Игра
- Цвет на экране только у огней. Огни считаются из секторов правила 21, а не задаются вручную.

## Код
Отступ в один пробел, плотные строки, комментарий только там, где причина неочевидна. Строки не длиннее 200 символов. Без npm-зависимостей и `eval`.

## Git
Коммит и push только по просьбе пользователя. Push в `main` публикует сайт.
