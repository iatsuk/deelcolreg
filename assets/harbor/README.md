# Графика портового прототипа

Оригинальные SVG для «Малой линии» 0.9. Растровая генерация и сторонние модели не используются.

- `old-port.svg`: фиксированная береговая композиция; авторский исходник — `scripts/create-harbor-art.py` (стандартная библиотека Python 3). Фон воды задаётся отдельно в CSS, чтобы край иллюстрации не был виден при изменении пропорций экрана.
- `rain-watch.svg`: самостоятельная иллюстрация дождя за стеклом рубки для узла `nina-workshop / trial`.

Камера первого файла соответствует `src/harbor-port-layout.js`. При изменении камеры нужно согласованно обновить генератор и проекцию. При правке берега и причала учитывать геометрию в `src/world-engine.js`. Текстовые подписи и кнопки не вшиты в рисунок.
